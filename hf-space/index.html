The problem RACT solves

A 2024 analysis of 623 million commits by GitClear and GitKraken found that AI-assisted code is already rotting codebases: more copy/paste, less refactoring, and a measurable decline in code movement.

RACT is the first agentic coding tool built to measure and defend against the four rot vectors that research identified — duplication, drift, dead code, and undocumented load-bearing logic.

Install

pip install rootact

Then scaffold a project for your favorite provider:

rootact --init-provider local
rootact --init-provider anthropic
rootact --init-provider openai
rootact --init-provider zai
rootact --init-provider moonshot
rootact --init-provider openrouter

Run a Root-Knot-anchored loop

rootact 'refactor the config loader to use dataclasses' --loop

Every generated file carries the Root Knot (_ROOT_KNOT = object()). Unsigned drift breaks the loop instead of compounding.

Anti-rot verifier arsenal

  • rootact novelty scan — flag structural near-duplicates.
  • rootact whisper — generate a codebase dialect brief before planning.
  • rootact auction list — review dead-code candidates.
  • rootact fence inspect --file f.py — ask why legacy code exists.

Why RACT instead of Cursor or Claude Code?

  • Own your pipeline. Mix local and cheap frontier models; no vendor lock-in.
  • Progress Oracle. Milestone-driven recursion, not time-based looping.
  • Operator Handshake. High-risk items queue for async review instead of blocking.
  • Local-first. Your code stays on your machine if you choose.
