## Master spec quote (v0.5.0 §Self-adjustment + §Repo fingerprint)

Three probe suites at `src/ract/memory/probes/`:

- Needle probe. Insert a specific fact at various depths in context of
  increasing size. Ask a question requiring the fact. Measure recall.
  Establishes empirical usable context window.
- Coherence probe. Provide long context with subtle inconsistency.
  Ask the model to identify it. Establishes reasoning quality at
  length.
- Instruction adherence probe. Provide long context with specific
  instruction at beginning. Ask a question requiring the instruction.
  Establishes instruction persistence.

Probe results feed a `model_capability` record in
`.rack/probes/capability.json`. Budgets derive from this record, not
from static defaults, when the record is populated. Default budgets
ship as fallback for a fresh install.

Every function failure emits a structured record. Aggregated over time,
patterns emerge. v0.5.0 ships the record shape and the aggregator; the
automated nightly narrowing job defers to v0.6.

Each repo builds a fingerprint over time: average function length,
typical import depth, LSP response time distribution, test suite
runtime. Fingerprint feeds retrieval defaults per repo. Persistence at
`.rack/fingerprint/repo.json`.
