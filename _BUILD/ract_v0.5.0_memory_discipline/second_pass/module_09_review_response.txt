Q2: PARTIAL
Evidence: `src/ract/trace/events.py` auto-computes `LEGAL_EVENT_KINDS` from the Literal via `get_args`, so it picks up additions. However, `src/ract/memory/events.py` maintains `MEMORY_EVENT_KINDS` as a separate frozenset (line ~40) that is a manual mirror — if someone adds a kind to the Literal but forgets this set, the NullEventSink would reject valid events. This is a drift risk, not a structural sync.
Fix: Derive `MEMORY_EVENT_KINDS` from `LEGAL_EVENT_KINDS` by filtering the seven known prefixes, or import from the trace module.

Q3: PARTIAL
Evidence: `src/ract/antilazy/pre_commit.py` `_load_manifest_files` and `_diff_touched_files` use raw string comparison. (a) POSIX vs Windows separators: `hunk.file_path` from git diffs typically uses forward slashes, but if a manifest uses backslashes on Windows, membership fails silently. (b) Absolute vs relative: no normalization — a manifest with `src/foo.py` vs diff with `/abs/path/src/foo.py` misses. (c) Empty `hunk.file_path` is filtered out by `if hunk.file_path` in `_diff_touched_files`, so it's silently ignored.
Fix: Normalize both sets via `os.path.normpath` and convert to POSIX separators before comparison.
