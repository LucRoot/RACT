## Master spec quote (v0.5.0 §Function contracts)

The four v0.5.0 verbs carry a change from user request through to
a candidate diff:

- `intake(request, context, provider) -> WorkOrder`. Budget 4k
  ceiling. Retrieval: recent git log (last 10 commits), README
  top section, mentioned-symbol signatures. No code bodies.
- `research(work_order, indexes, provider) -> ResearchBundle`.
  Budget 10k ceiling. 7-step retrieval pattern (symbol / keyword /
  semantic / graph / commit-history), SIGNATURE format.
- `plan(work_order, research_bundle, indexes, provider) ->
  ChangePlan`. Budget 9k ceiling. May issue up to 3 mid-invocation
  retrieve calls at 500 tokens each.
- `edit(change_plan, indexes, provider) -> CandidateDiff`. Budget
  18k ceiling. Cascade: FULL for targets, SIGNATURE/BODY_ONLY for
  non-targets; targets alone > input_target raises
  BoundedContextError. Output discipline: AST validation + retry-
  on-parse-error up to twice. Grammar-constrained generation
  (Outlines) defers to v0.6.

Master spec §Bounded scope: `verify / review / commit / document`
