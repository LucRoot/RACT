RACT

Model-agnostic, local-first agentic coding with signed receipts and an anti-rot verifier arsenal.

Quickstart

ract run        # start a Rooted agent loop on your intent
ract doctor     # verify project config and provider health
ract fence      # inspect why legacy code exists before changing it

Why RACT?

  • Local-first: run entirely on your own hardware and data.
  • Model-agnostic: route work across local and frontier providers.
  • Anti-rot: built-in consolidate, novelty scan, auction, and fence verbs.
  • Auditable: signed run receipts and tamper-evident chains.
