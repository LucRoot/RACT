# RACT LEADERBOARD

**SUBSTRATE §11 signal 16 + ALM module_07.** This leaderboard shows
RACT's numbers against two established public benchmarks — Aider
Polyglot (edit + test-feedback loop, function-to-file scale) and
SWE-bench Lite (repo-scale issue-to-patch) — plus the module-internal
conformance (module_04) and security (module_03) corpora that the
router already gates on. The v0.4.0 ALM extension adds
``claimed_pass_rate``, ``attested_pass_rate``, and
``attestation_gap`` columns: attested is the subset of claimed runs
whose rootknot metadata verifies under all three signatures (RK-1,
RK-3, AL-1) with clean reversal taint. Regenerated by
``evals/leaderboard/update.py`` from the most recent per-provider
report under ``evals/runs/``; it is the canonical published record.
Module-internal RESULTS.md files remain as the source-of-truth for
the columns they contribute (Lateral Chain branch E, substrate
module_07).

## Notes

- Rows are sorted by provider name (ASCII ascending).
- Empty cells (`-`) indicate no report yet for that provider on that
  corpus; the corresponding runner is scaffolded but not exercised
  in this environment. See
  ``_BUILD/ract_v0.4.0_substrate/module_07.md`` and
  ``_BUILD/ract_v0.4.0_antilazy/module_07.md`` "Flagged gaps" for the
  list of things module_07's close explicitly does not include.
- The `fake` provider row proves the harness — the FakeProvider is
  the fixture path both runners default to when
  ``RACT_EVAL_ENABLED`` is unset (Lateral Chain branch B).
- ``claimed_pass_rate`` denominator counts every problem in the
  subset (passed + failed + skipped); ``attested_pass_rate``
  denominator EXCLUDES runs with no rootknot file (crashed before
  rootknot generation) — see ALM module_07 Second Pass Q2 and
  ADR-0025 for the exclusion rationale.
- ``attestation_gap`` = ``claimed - attested`` (clamped to
  zero-or-positive). Interpretation (ALM module_07 Lateral Chain
  branch C): gap > 0.20 is a provider signal (reward-hacking rate);
  gap 0.05 to 0.20 is a mixed signal (partly gate strictness, partly
  provider); gap under 0.05 is measurement noise. Thresholds are
  speculative until a v0.5 empirical calibration lands (Flagged gap
  in module_07).
