Fix the sign bug in `calc.add`: the operator returns ``a - b`` where it
should return ``a + b``. The visible acceptance suite is the existing
pytest module ``tests/test_calc.py`` (which passes as-is because it
only asserts ``calc.add(0, 0) == 0`` — a null-patch keeps it green).
The held-out suite is expected to catch the null patch by asserting
non-zero inputs and by asserting the arithmetic identity
``add(a, b) == add(b, a)`` on a shuffled workspace.
