Why RACT?

A 2024 analysis of 623 million commits by GitClear and GitKraken found that AI-assisted code is already rotting codebases: more duplication, less refactoring, and a decline in code movement. RACT measures and defends against the four rot vectors: duplication, drift, dead code, and undocumented load-bearing logic.

Anti-rot workflow

consolidate

Find near-duplicate modules, preview merges, and queue them for approval.

novelty scan

Block near-duplicates before they are written.

auction

Identify dead code by reachability and queue it for removal.

fence

Ask why legacy code exists before changing it.

Quick start

pip install rootact
rootact init --template python-package --provider local
rootact "refactor to async" --loop
rootact consolidate --dry-run
