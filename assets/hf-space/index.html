RACT

Model-agnostic, local-first agentic coding with signed receipts and an anti-rot verifier arsenal.

Why RACT?

AI-assisted code is already rotting codebases: more copy/paste, less refactoring, and a measurable decline in code movement. RACT is the first agentic coding tool built to measure and defend against the four rot vectors — duplication, drift, dead code, and undocumented load-bearing logic.

Anti-rot verifiers

ract consolidate

Find near-duplicate modules, preview the merge as a unified diff, and queue cleanups for operator approval.

ract novelty

Measure how much a new artifact resembles existing code. Blocks verbatim and renamed clones before they are written.

ract auction

Identify dead code by reachability and queue removal proposals.

ract fence

Ask why legacy code exists before changing it. Chesterton's Fence for your own codebase.

Quick start

pip install rootact
rootact --init-provider local
rootact "write tests for the widget module"
rootact --loop

Local-first and model-agnostic

Your code stays on your machine. RACT routes work to local models via Internal, to OpenAI-compatible endpoints, or to other providers through a pluggable provider interface. Every plan and every result is Rooted[T] — it carries the assumption, confidence, and provenance that justify it.
